# Как запустить ноутбук

В `Research.ipynb` весь код исследования: работа с API, отбор и объединение статей, расчёт показателей, граф и сравнение по годам.

Нужны Python 3.11 или 3.12. Из папки с ноутбуком выполните:

```bash
python -m pip install -r requirements_notebook.txt
jupyter lab Research.ipynb
```

В Jupyter выберите **Restart Kernel and Run All**. Папка `data` и файл `clean_viewer.template.html` должны находиться рядом с ноутбуком. Таблицы и рисунки сохраняются в `notebook_results`. Установить библиотеки нужно с интернетом, сами расчёты работают на сохранённых данных.

## Сбор через API

В первом разделе есть код запросов к OpenAlex. По умолчанию `REFRESH_API = False`, поэтому используются сохранённые ответы от 10.11.2026. Если поставить `True`, новые ответы сохранятся отдельно в `notebook_results/api_collection`. При наличии ключа его можно передать через переменную окружения `OPENALEX_API_KEY`.

Повторный сбор не заменяет данные отчёта автоматически: состав корпуса и ссылки из PDF относятся к сохранённому набору. Поэтому новый результат поиска нужно обрабатывать отдельно.

## Что внутри

1. OpenAlex: поисковые запросы, загрузка соседних статей и проверка ID.
2. Отбор кандидатов и объединение версий.
3. Обычный и дробный подсчёт, PageRank и итоговая таблица.
4. Граф на Python: сообщества, раскладка и сохранение SVG, PNG и HTML.
5. Ежегодные цитирования, Gini и корреляция Спирмена.

В ноутбуке 31 выполненная ячейка кода и три рисунка. Данные соответствуют числам в отчёте.
